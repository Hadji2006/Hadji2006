## How I build

```text
design → architecture → implementation → hardening → release → observe
```

- **Security by default** — least-privilege permissions, prepared statements, hardened server configs, WebView lockdown, signed release builds.
- **Ship complete artifacts** — versioning, changelogs, privacy policies, and data-safety declarations are part of "done", not afterthoughts.
- **Performance is UX** — offline-first behavior, zero-analytics footprint, hand-written CSS instead of framework bloat.
- **Reach matters** — multi-language UIs, RTL support, readable contrast, keyboard-friendly markup.

### 01 · Calc Studio — offline scientific & programmer calculator for Android

A single hardened WebView screen driven by a Kotlin host activity: scientific functions, HEX/DEC/OCT/BIN conversion with an interactive bit board, IEEE 754 inspection, overflow-aware machine arithmetic, history, themes, and 130 languages with automatic RTL. Ships with **no internet permission, no ads, no analytics**.

**Built with:** `Kotlin` `Android (minSdk 24 → target 35)` `Gradle Kotlin DSL` `Vanilla JS engine`

**Focus:** Offline-first · Attack-surface reduction · Signed release pipeline · Global reach
